Assemblage

Describe what you're modelling. Get a reference board, inside Blender.

Install in one drag

  1. Open Blender 5.2 or newer.
  2. Drag this button onto the Blender window:
    Download Assemblage
  3. Click Install when Blender asks. If it asks to allow online access, say yes: Assemblage needs it to search.
  4. In the 3D viewport, press N and open the Assemblage tab.

Prefer a file? Click the button instead of dragging it: the zip downloads, then drag the zip into Blender. Mac + Safari: if it unzips by itself, right-click the button and choose Download Linked File. Installed by dragging? Blender will offer updates in Preferences → Get Extensions.

Free and open source (GPL-3.0). It doesn't generate images: it finds real reference photos and ranks them with an AI model that runs on your computer. Privacy · Source code · Report a problem
